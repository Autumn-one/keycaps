KeyCaps 可以免费使用吗？+

可以。KeyCaps 是独立的免费快捷键工具，提供 Caps 快捷键、普通动作、应用分流和配置管理等功能。

配置快捷键需要写脚本吗？+

不需要。你可以通过可视化动作编辑器选择按键、动作和窗口匹配条件，也可以针对指定应用添加分流动作。

可以把配置带到另一台电脑吗？+

可以。软件支持配置导入、导出和 WebDAV 同步。你可以在配置页面备份、迁移自己的快捷键设置。

支持哪些系统？+

当前提供 Windows x64 EXE 标准安装包，适用于 Windows 10 / 11，不捆绑 .NET 运行库。已有兼容运行库时直接复用；缺失时，安装向导会从微软官方下载并安装。
