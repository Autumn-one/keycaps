# KeyCaps

独立的 Windows CapsLock 快捷键工具，保留可视化模式编辑、普通动作、窗口匹配、应用分流、输入浮窗、公告与关于页。

[下载最新版本](https://github.com/Autumn-one/keycaps/releases/latest) · [所有版本](https://github.com/Autumn-one/keycaps/releases)

下载 Windows x64 ZIP，解压到固定目录后运行 KeyCaps.exe。软件启动时及每 10 分钟检查更新，沿用多镜像切换、断点续传、SHA256 和大小校验。

此仓库提供公开发行包与更新配置。配置保存在当前用户 AppData/Roaming/KeyCaps，使用统计可在配置页关闭。
